# Saturn

Three.js Saturn with full ring system (D-to-F rings, Cassini Division) and five
moons (Titan, Rhea, Enceladus, Mimas, Iapetus) on scaled inclined orbits.

Single-file, thermal-constrained build: no post-processing, shadow maps off,
fps-capped with a Low/Med/High quality selector (Low default), render loop
stops when the tab is hidden. Optional Web Audio soundtrack, off by default.

## Play

Live: https://arecibo-sys.github.io/saturn/

Or open index.html directly in a browser.
